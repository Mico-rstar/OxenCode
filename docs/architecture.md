# OxenCode 架构设计文档

## 架构概述

### 系统概述

OxenCode 是一个学习型的 AI 编程助手项目，专注于实践 Agent 工程化的核心技术。系统采用命令行交互模式，通过自然语言对话的方式帮助用户完成软件开发任务。

**核心特性：**
- 流式输出 - 实时显示 AI 思考过程，提供打字机效果的交互体验
- 工具调用 - 支持文件操作（Glob/Grep/View/Write/Edit）和系统命令（Bash）
- 权限系统 - 危险操作需用户确认，支持持久化授权策略
- 多轮对话 - 维护完整的对话历史和上下文记忆
- 取消支持 - 随时中断运行中的任务，避免浪费 Token

## 部署模式

### 单机部署模式

OxenCode 设计为单机 CLI 工具，直接在用户开发环境中运行：

```
┌─────────────────────────────────────────────────┐
│              Developer Machine                   │
│                                                 │
│  ┌───────────────────────────────────────────┐ │
│  │           OxenCode CLI                     │ │
│  │                                           │ │
│  │  ┌─────────┐  ┌─────────┐  ┌──────────┐  │ │
│  │  │Terminal │─▶│  Agent  │─▶│ LLM API  │  │ │
│  │  │  (TUI)  │  │  Core   │  │ (Remote) │  │ │
│  │  └─────────┘  └─────────┘  └──────────┘  │ │
│  │                                           │ │
│  │  ┌─────────┐  ┌─────────┐  ┌──────────┐  │ │
│  │  │File Sys │◀─│  Tools  │◀─│ Permission│ │ │
│  │  └─────────┘  └─────────┘  └──────────┘  │ │
│  └───────────────────────────────────────────┘ │
│                                                 │
│  Configuration: ~/.oxencode/                   │
│  Cache/History: ~/.oxencode/                   │
└─────────────────────────────────────────────────┘
                          │
                          ▼ HTTPS
                  ┌───────────────┐
                  │  LLM Provider │
                  │  (Claude API) │
                  └───────────────┘
```
